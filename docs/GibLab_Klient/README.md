# GibLab Klient — dokumentacja projektu

Ten folder jest punktem startowym do dalszej pracy nad uproszczoną aplikacją dla klienta.

## Jak używać w nowej rozmowie z ChatGPT / Codex

Otwórz najpierw:
- `START_HERE.md`
- `GIBLAB_KLIENT_MASTER.md`
- `DECISIONS.md`
- `LESSONS.md`

## Główna idea

Nie budujemy kopii dużego „Magazyn GibLab”. Budujemy prostą aplikację skupioną na:
1. zleceniach do rozkroju,
2. resztkach i magazynie płyt,
3. zakupach,
4. klientach i płatnościach,
5. integracji z GibLab,
6. przyjmowaniu zleceń przez Telegram i AI.

## Najważniejsze pliki

- `START_HERE.md` — szybki kontekst do wznowienia pracy.
- `GIBLAB_KLIENT_MASTER.md` — główna specyfikacja.
- `RESZTKI_I_ETYKIETY.md` — moduł resztek, półek i etykiet.
- `TELEGRAM_AI_GIBLAB.md` — przepływ Telegram → AI → GibLab.
- `MVP_UI.md` — uproszczone ekrany.
- `DATA_MODEL.md` — proponowany model danych.
- `ROADMAP.md` — kolejność wdrożenia.
- `DECISIONS.md` — decyzje już podjęte.
- `LESSONS.md` — lekcje z obecnego Magazyn GibLab.
- `QUESTIONS_OPEN.md` — kwestie do doprecyzowania.
