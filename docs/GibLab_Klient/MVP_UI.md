# GibLab Klient — proponowane UI

## Zasada

Mniej ekranów, mniej przycisków, duże czytelne akcje.

## 1. Dashboard

Karty:
- Nowe zlecenia
- Do sprawdzenia
- Do rozkroju
- Gotowe
- Niezapłacone
- Braki materiałowe

Niżej:
- ostatnie zlecenia,
- ważne braki,
- zarezerwowane resztki.

## 2. Zlecenia

Lista:
- numer,
- klient,
- termin,
- materiał,
- liczba formatek,
- status,
- płatność.

Duże akcje:
- Nowe zlecenie
- Importuj
- Sprawdź AI
- Wyślij do GibLab

## 3. Podgląd AI

Tabela tylko do weryfikacji:
- Długość
- Szerokość
- Ilość
- Materiał
- Krawędzie
- Uwagi

Nie budować dużego formularza ręcznego jako głównego workflow.

## 4. Resztki

Filtry:
- typ materiału,
- dekor,
- grubość,
- rozmiar,
- półka,
- status.

Widok:
- materiał,
- wymiar,
- półka,
- status,
- QR.

Akcje:
- Drukuj etykietę
- Rezerwuj
- Przenieś
- Zużyto

## 5. Materiały

Tabela:
- kod,
- nazwa,
- typ,
- grubość,
- pełne płyty,
- resztki,
- dostępne,
- minimum.

## 6. Zakupy

Prosta tabela:
- materiał,
- stan,
- potrzeba,
- dokupić,
- dostawca,
- status.

## 7. Klienci

Lista:
- nazwa,
- telefon,
- liczba otwartych zleceń,
- saldo.

## 8. Płatności

Na karcie zlecenia:
- wartość,
- suma wpłat,
- pozostało,
- historia wpłat.

## 9. Ustawienia

Tylko rzeczy potrzebne:
- połączenie GibLab,
- folder wymiany,
- drukarka etykiet,
- reguły półek,
- minimalna resztka,
- Telegram,
- użytkownicy.
