Jak pracowac w programie

            
Kolejnosc pracy: klient, zamowienie, pozycje, formatki, GibLab, produkcja, platnosci i magazyn.


            

              

                
1. Klient i zamowienie

                
    
                  
  1. Wejdz w Klienci i dodaj klienta.
    2. 
                  
  2. Wejdz w Zamowienia i kliknij + Dodaj nowe zamowienie.
    3. 
                  
  3. Uzupelnij klienta, nazwe zlecenia, termin i status.
    4. 
                  
  4. Jezeli zlecenie jest pilne, wpisz procent w polu Doplata pilna %.
    5. 
                  
  5. Kliknij Zapisz zamowienie.
    6. 
                

              


              

                
2. Pozycje i formatki

                
    
                  
  1. Wejdz w Formatki.
    2. 
                  
  2. Wybierz zamowienie i wpisz nazwe pozycji, np. fronty, polwalek, cokol.
    3. 
                  
  3. Wybierz material z listy GibLab albo wpisz material recznie.
    4. 
                  
  4. Formatki dodasz z tekstu, zdjecia, Excela albo przyciskiem Dodaj formatke.
    5. 
                  
  5. Zaznacz formatki checkboxami i wybierz szablon technologii.
    6. 
                

              


              

                
3. Skan zdjecia / AI

                
    
                  
  1. Kliknij Import tekst / zdjecie.
    2. 
                  
  2. Wybierz zdjecie listy formatek.
    3. 
                  
  3. Jezeli wynik jest slaby, uzyj Ponow skan AI.
    4. 
                  
  4. Sprawdz wymiary przed dodaniem do pozycji.
    5. 
                  
  5. Kliknij Dodaj zaznaczone do pozycji.
    6. 
                

              


              

                
4. GibLab rozkroj

                
    
                  
  1. Dla kilku pozycji uzywaj Wyslij pozycje osobno.
    2. 
                  
  2. W GibLab otworz plik .project dla konkretnej pozycji.
    3. 
                  
  3. Po rozkroju zapisz wynik w GibLab.
    4. 
                  
  4. W programie kliknij Odbierz wynik.
    5. 
                  
  5. Sprawdz liczbe arkuszy, m2 i status pozycji.
    6. 
                

              


              

                
5. Produkcja

                
    
                  
  1. Wejdz w Produkcja.
    2. 
                  
  2. Wybierz stanowisko: CNC, Oklejarka albo Lakiernia.
    3. 
                  
  3. Operator wpisuje swoje imie.
    4. 
                  
  4. Kliknij Start, kiedy praca zaczyna sie na stanowisku.
    5. 
                  
  5. Problem zglaszaj przyciskiem Problem.
    6. 
                

              


              

                
6. Ceny i platnosci

                
    
                  
  1. Ceny technologii ustawiasz w Cennik technologii.
    2. 
                  
  2. Wartosc zamowienia liczy sie z pozycji, formatek i doplat.
    3. 
                  
  3. Wplaty dodajesz w zakladce Zamowienia.
    4. 
                  
  4. Saldo klienta widac w Klienci i na liscie zamowien.
    5. 
                

              


              

                
7. Materialy, dostawy i stany

                
    
                  
  1. Nowe materialy dodajesz w Materialy.
    2. 
                  
  2. Dostawy wpisujesz w Dostawy.
    3. 
                  
  3. Stan rosnie dopiero po kliknieciu Zaksieguj dostawe.
    4. 
                  
  4. Aktualne ilosci sprawdzisz w Stany.
    5. 
                  
  5. Braki i potrzeby zakupowe sprawdzisz w Zakupy.
    6. 
                

              


              

                
8. Resztki i backup

                
    
                  
  1. Resztki po rozkroju zapisuj w Resztki z wymiarem i lokalizacja regalu.
    2. 
                  
  2. Przy kilku komputerach rezerwuj resztke pod projekt.
    3. 
                  
  3. Przed wiekszymi zmianami rob Backup.
    4. 
                  
  4. Nie usuwaj bazy danych ani plikow runtime.
    5. 
                

              

            

          

        


        

          

            
            
            
          

          
Backup zapisuje kopię bazy SQLite w folderze data/backups. Przed przywróceniem program tworzy dodatkową kopię aktualnej bazy.
